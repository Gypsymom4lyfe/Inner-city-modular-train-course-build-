# Inner-city-modular-train-course-build-

Phase 1 repository package for the bidirectional inner-city data center rail pod.

## Deliverables

- `/phase-1/specification/mechanical-spatial-design-spec.md` — envelope, gauge, symmetry, and layout assumptions.
- `/phase-1/specification/pace-program-track-portsmouth.md` — Portsmouth PACE curriculum framework for fabrication, physical security, and environmental monitoring.
- `/phase-1/cad/inner_city_pod_outer_shell.step` — simplified STEP model of the low-profile bidirectional shell.
- `/phase-1/cad/inner_city_pod_frame_skeleton.step` — simplified STEP model of the frame, cross-members, battery pan, and cassette support structure.
- `/phase-1/cad/inner_city_pod_phase1_assembly.step` — combined Phase 1 assembly.
- `/phase-1/reports/structural-stress-simulation-report.md` — preliminary structural load and vibration assessment.
- `/phase-1/blueprints/spatial-integration-blueprint.md` — mounting-point map and modular integration blueprint.

## Design basis

This baseline assumes a 12,000 mm bidirectional pod envelope, 2,900 mm maximum body width, a low center-of-gravity battery pan, and a standard-gauge 1,435 mm track interface intended for restricted urban industrial clearances. The package is set up as a first-pass engineering submission that can be refined in downstream CAD and solver workflows.

## Program extension

This repository also includes a Portsmouth PACE Center curriculum track that adapts the inner-city rail compute cart concept into a hands-on education program centered on model fabrication, physical security, and environmental monitoring. See `/phase-1/specification/pace-program-track-portsmouth.md` for the full framework.
